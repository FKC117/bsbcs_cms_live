BSBCS Admin Step Guide

Detailed staff guide for daily admin actions. Each card says where to go, what to click, which fields/ticks to set, and what happens after saving.

Create and Configure Events

Admin Home > Registration > Events > Add event

Create a Basic Event

  1. Go to Registration > Events.
  2. Click Add event.
  3. Enter Name, Year, Slug if required, Start date, End date, and Location.
  4. Add Slogan, Description, keywords, and SEO fields if available.
  5. Upload Event logo. This is used as fallback if hero image is missing.
  6. Upload Event hero image. This is used in event cards/archive cards first.
  7. Set Event status to active/upcoming/open according to current event state.
  8. Set Registration open if users should register now; set closed if not ready.
  9. Click Save.
  10. Open the public event page and confirm title, date, images, and buttons are correct.
Registration > Events > Open event

Set Regular Registration Fee

  1. Open the event from Registration > Events.
  2. Find the payment/amount section.
  3. If the event is paid, set Payment required to true/checked.
  4. Enter the normal attendee fee in Amount.
  5. If the event is free for everyone, set Payment required false/unchecked or set amount to 0.
  6. Click Save.
Paid: users need approval and payment before final confirmation.
Free: users still need approval, but payment record should become BDT 0/completed.
Registration > Events > Open event

Allow Members to Join Free or With Discount

  1. Open the event.
  2. Find the member registration fields.
  3. If members should attend free, turn on the member-free setting or set Member registration fee to 0.
  4. If members should pay less, enter the reduced amount in Member registration fee.
  5. If members should pay the same as regular users, leave member fee blank or same as regular fee according to policy.
  6. Save the event.
  7. Test with an active member account and a non-member account.
Free: active member sees free member registration.
Discount: active member sees member fee and pays after approval.
Registration > Events > Open event

Make an Event Members Only

  1. Open the event.
  2. Find Registration audience or equivalent member-audience field.
  3. Select Members only if only approved active members can register.
  4. Set member fee/free setting as needed.
  5. Save.
  6. Test as non-member: regular form should not open; user should be guided to membership.
  7. Test as active member: member registration should be available.
Registration > Events > Open event

Close Registration or Abstract Submission

  1. Open the event.
  2. To stop event registration, set Registration to closed/off.
  3. To stop abstracts, turn off the publication/abstract tab or related visibility field.
  4. Set event status to closed/completed when the event is over.
  5. Save.
  6. Check public event menu: closed actions should not appear.

Membership Admin Actions

Website > Membership Types > Add membership type

Create Membership Type

  1. Go to Website > Membership Types.
  2. Click Add membership type.
  3. Enter name, slug, description, amount, and duration years.
  4. If it is lifetime membership, tick Is lifetime.
  5. Tick Is active if users should be able to select it.
  6. Set order if you want a specific display order.
  7. Save.
Website > Members

Approve a Membership Application

  1. Go to Website > Members.
  2. Filter/search pending applications.
  3. Open the member record.
  4. Review user, profile details, institution, position, bio, image, specialties, and membership type.
  5. If accepted, set approval status to approved and active member to true/checked.
  6. If rejected, set approval status to denied/rejected and keep active member false.
  7. If membership expiry is known, set valid-until/expiry date.
  8. If expiry is unknown, leave it blank; frontend should show a friendly message.
  9. Save.
Approve: user gets active member benefits.
Deny: user stays normal user, not member.
Website > Membership Payments

Check Membership Payment

  1. Go to Website > Membership Payments.
  2. Search by member, user, invoice, or transaction ID.
  3. Open the payment record.
  4. Check amount, status, payment ID, trxID, invoice, and email state.
  5. If payment is completed but member is not active, open the related member and activate after confirming payment.
Website > Membership Benefit Modals / Membership Benefit Items

Create Membership Benefits Modal

  1. Go to Membership Benefit Modals.
  2. Enter heading, subheading, and CTA text if using text modal.
  3. Add benefit rows from Membership Benefit Items.
  4. If client provides one designed image, upload it in the modal image field.
  5. If image exists, system shows image modal only.
  6. If no image exists, system shows heading/subheading/items.
  7. If nothing exists, modal does not show.
  8. Tick Show on homepage if it should appear on homepage.
  9. Save and check homepage/member pages.

Participant Admin Actions

Registration > Participants

Approve or Deny Participant

  1. Go to Registration > Participants.
  2. Filter by event or search name/email/phone.
  3. Open the participant.
  4. Review participant details and registration type.
  5. If accepted, mark Approved true/checked and Denied false/unchecked.
  6. If rejected, mark Denied true/checked and Approved false/unchecked.
  7. Save.
  8. For paid event, confirm a payment status exists and payment email/page is available.
Registration > Participants / Payment Statuses

Handle Already Registered User

  1. Search participant by event and email/phone.
  2. If participant exists and is pending, tell user it is under review.
  3. If participant is approved but payment status is unpaid, tell user to complete payment.
  4. If participant is approved and payment completed/zero, tell user registration is already confirmed.
Registration > Registration Kits

Issue Registration Kit

  1. Go to Registration Kits.
  2. Search participant/event.
  3. Confirm participant is approved and paid/free completed.
  4. Set kit issued status/date.
  5. Save or export list for event desk.

Corporate Admin Actions

Registration > Corporate Account Requests

Approve Corporate Access

  1. Go to Corporate Account Requests.
  2. Open the request.
  3. Review company, contact person, designation, email, phone, and notes.
  4. If accepted, set status to approved and save.
  5. If rejected, set status to rejected/denied and save.
  6. On approval, system creates or links a user and creates corporate account.
  7. System sends approval email with corporate login instructions.
Registration > Corporate Accounts

Manage Corporate Account

  1. Go to Corporate Accounts.
  2. Open the company account.
  3. Check linked user, company name, contact email, and phone.
  4. If company should access dashboard, keep status approved/active.
  5. If company should not access dashboard, change status to inactive/disabled according to available choices.
  6. Save.
Registration > Corporate Event Registrations

Review Uploaded Corporate List

  1. Go to Corporate Event Registrations.
  2. Open the event registration submitted by the company.
  3. Review attendee inline rows.
  4. Check each row for matched user, matched member, duplicate/conflict notes, fee category, and review status.
  5. If all pending attendees are acceptable, go back to list page, select this corporate registration, and choose action Step 2 - Approve all pending attendees and email participants.
  6. If only some are acceptable, open each attendee or use Corporate Event Attendees to approve/deny individually.
Registration > Corporate Event Attendees

Approve or Deny One/Few Corporate Attendees

  1. Go to Corporate Event Attendees.
  2. Filter by event and pending status.
  3. Select attendee rows.
  4. If accepted, choose action Step 2 - Approve selected attendees and email participants.
  5. If rejected, choose action Deny selected attendees.
  6. Approved attendees become normal participants and receive participant confirmation.
  7. Denied attendees remain excluded from invoice/payment.
Registration > Corporate Event Registrations

Create Corporate Invoice After Approval

  1. After approving all or some attendees, return to Corporate Event Registrations.
  2. Select the corporate registration row.
  3. Choose action Step 3 - Create corporate invoice/payment for approved attendees.
  4. System creates corporate payment for approved attendees not already invoiced.
  5. System generates PDF invoice with approved attendee list.
  6. System emails corporate contact with total submitted, approved, denied, pending, included in invoice, amount, payment link, and attached PDF.
Mixed list: approved rows are invoiced; denied rows are excluded; pending rows wait for later review.
Registration > Corporate Payments

Resend or Regenerate Corporate Invoice

  1. Go to Corporate Payments.
  2. Select the payment record.
  3. Choose Regenerate corporate invoice PDF if PDF needs update.
  4. Choose Send corporate invoice email if company needs the email again.
  5. Open the payment record to view invoice link, status, amount, transaction ID, and attendees.

Payment Admin Actions

Registration > Payment Statuses

Check Individual Event Payment

  1. Go to Payment Statuses.
  2. Search by participant name/email, event, merchant invoice number, transaction ID, or trxID.
  3. Open payment record.
  4. Check amount and status.
  5. If status is unpaid, user still needs payment.
  6. If status is completed/paid, user is financially confirmed.
  7. If status is failed, user must retry payment.
  8. Open invoice file if available.
Registration > Bkash Data

Audit bKash Data Before Manual Correction

  1. Go to Bkash Data.
  2. Search by merchant invoice number, payment ID, or trxID.
  3. Compare amount and transaction status with Payment Status/Corporate Payment.
  4. If bKash says success but app status is wrong, then consider manual correction.
  5. Never manually mark paid without matching bKash evidence.
Registration > Pending Payment Reminders

Send/Track Payment Reminder

  1. Go to Pending Payment Reminders.
  2. Find unpaid participant/payment target.
  3. Check reminder status and last sent date.
  4. Send reminder only according to event/client policy.

Abstract Admin Actions

Registration > Abstract Submissions

Approve Abstract for Presentation or Poster

  1. Go to Abstract Submissions.
  2. Filter by event.
  3. Open the abstract.
  4. Review title, authors, institution, introduction, methods, results, conclusion, image, and presentation file.
  5. If accepted for presentation, set presentation approval or use presentation approval action.
  6. If accepted for poster, set poster approval or use poster approval action.
  7. Save or run selected action.
  8. System sends approval email for selected approval type.
Registration > Upload Abstract Books / Upload Note Books

Upload Final Abstract Book or Notebook

  1. Go to the upload model.
  2. Click add.
  3. Select event.
  4. Upload final PDF/file.
  5. Save.
  6. Check event page download tab/button.

Program, Speaker, Sponsor, and Media Actions

Registration > Hall Rooms / Program Days / Time Slots

Create Program Timing Structure

  1. Create Hall Room for each venue/hall.
  2. Create Program Day for each event date.
  3. Create Time Slot and select program day, hall room, start time, and end time.
  4. Save each item before creating schedule entries.
Registration > Chairpersons / Moderators / Panelists / Featured Speakers

Add People for Program

  1. Open the relevant person model.
  2. Click add.
  3. Enter name, designation, organization, image, bio, and event where available.
  4. Save.
  5. For Featured Speakers, check public event page and speaker modal.
Registration > Program Schedules

Create Program Schedule

  1. Go to Program Schedules.
  2. Click add.
  3. Select event and time slot.
  4. Enter title/topic and presenter.
  5. Select chairperson, moderator, and panelists if applicable.
  6. Save.
  7. Use schedule email/export actions only after schedule is final.
Registration > Sponsors / Event Images / Event Videos / Program Schedule PDFs

Add Event Assets

  1. Add sponsors with event, name, logo, category, and order.
  2. Add event images for gallery.
  3. Add event videos with URL/file fields.
  4. Upload schedule PDF if a downloadable PDF is needed.
  5. Save and check public event pages.

Website Content Admin Actions

Website > Site Settings

Update Logo, Favicon, Contact, Footer

  1. Go to Site Settings.
  2. Open existing settings record or add one if none exists.
  3. Upload logo and favicon.
  4. Set contact email, phone, location, footer content, social links.
  5. Upload membership invoice logo if invoices need a special logo.
  6. Save and check frontend header/footer and invoice PDFs.
Website > Navigation Links

Update Menu

  1. Go to Navigation Links.
  2. Click add for a new menu item or open existing link.
  3. Set label, URL/page, order, and active state.
  4. If it is a dropdown child, select parent/dropdown settings.
  5. Save and check desktop/mobile navigation.
Website > Hero / Carousel / News / Quick Access / Statistics

Update Homepage Blocks

  1. Open the relevant homepage model.
  2. Add title, subtitle, link, image, order, and active status where available.
  3. Use active checkbox to show/hide without deleting.
  4. Save and check homepage.
Website > Past Events / Past Event Speakers / Sessions / Sponsors

Create Past Event Archive

  1. Go to Past Events.
  2. Add title, slug, year, date, venue, description, logo, hero image.
  3. Add past event speakers, sessions, and sponsors.
  4. If hero image exists, cards use hero image.
  5. If hero image is missing, cards use event logo.
  6. If both are missing, cards use site logo.
  7. Save and check /past-events/ and detail page.
Website > Board / Committees / Values / Timeline / Partnerships / Awards / Resources / Webinars / Media / Annual Reports

Maintain Other Website Pages

  1. Open the relevant model.
  2. Add title/name, description, image/file/link, order, and active status where available.
  3. Use order field to control display order.
  4. Use active checkbox to temporarily hide content.
  5. Save and check the related frontend page.

Email, Certificate, Feedback, and Post Event Actions

Registration > Thank You Emails

Send Thank You Emails

  1. Go to Thank You Emails.
  2. Create/populate thank-you email records for event.
  3. Review subject and body.
  4. Select records and use send action.
  5. Check sent status/reporting.
Registration > Certificates

Prepare Certificates

  1. Go to Certificates.
  2. Select participant/event and certificate type/details.
  3. Save.
  4. Generate/download/distribute according to event policy.
Registration > Feedback Questions / Feedback Responses

Feedback Workflow

  1. Create feedback questions for event.
  2. After event, open feedback responses.
  3. Filter/export responses for reporting.
Registration > Email Groups / Bulk Emails / Bulk Email Reporting

Bulk Email Workflow

  1. Create or import email group.
  2. Create bulk email subject/body.
  3. Select target group.
  4. Send from admin action.
  5. Check Bulk Email Reporting for delivery/recipient status.

Deployment and Emergency Steps

Live VM terminal

Deploy New Code

  1. Backup database using mysqldump --no-tablespaces.
  2. Backup media folder using tar.
  3. Go to project folder and run git status.
  4. If clean, run git pull origin main.
  5. Activate venv.
  6. Run python manage.py check.
  7. Run python manage.py showmigrations.
  8. Run python manage.py migrate.
  9. Run python manage.py collectstatic --noinput.
  10. Restart Apache.
  11. Check Django log and Apache error log.
Troubleshooting

Common Admin Checks

  1. If migration says duplicate table/column, confirm schema already exists before fake migration.
  2. If invoice is missing, regenerate invoice and check media write permission.
  3. If email is missing, check SMTP settings, spam, recipient email, and logs.
  4. If host error appears, add only real BSBCS domain to allowed hosts; ignore random bot domains.
  5. If payment mismatch appears, check bKash data before editing payment status.
